## 📱 Core Features

### **Phase 1 (MVP - 6 weeks)**
- ✅ Prayer Times (10+ calculation methods)
- ✅ Qibla Compass (offline)
- ✅ Quran Reader (offline, Bangla/English)
- ✅ Dua Collection (200+ duas)
- ✅ Tasbeeh Counter (digital)
