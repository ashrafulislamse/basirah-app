## 🎯 Key Decisions

### ✅ Approved for Phase 1:
- Hybrid approach (4 theme modes)
- Prayer-Aware as default
- User can switch to Light/Dark/System anytime
- 3 prayer-aware states (Dawn/Day/Night)

### 📝 Documented for Future:
- 6-theme mode (more granular)
- Ramadan special theme (seasonal)
- Custom color themes (community)
- Theme scheduling (power users)

### ❌ Not Doing:

- Complex theme animations in Phase 1
